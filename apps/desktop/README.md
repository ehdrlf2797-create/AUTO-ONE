# 데스크톱 앱 (예정)

PC용 데스크톱 앱은 웹 앱과 공통 UI 및 API 계약을 공유하는 방향으로 설계합니다. 현재 실행 가능한 데스크톱 바이너리나 네이티브 기능은 포함되어 있지 않습니다.

Phase 1 이후 Tauri 기반 데스크톱 셸을 검토합니다.

예정 기능:
- PC 시작 시 선택적 실행 및 연결 상태 표시
- 허용된 로컬 자동화 작업 요청
- 작업별 권한과 범위 확인
- 중지 및 취소 기능
- 로컬 감사 로그와 오류 진단

운영체제 권한이 필요한 기능은 사용자에게 목적과 접근 범위를 설명한 뒤 별도로 허용받습니다.
