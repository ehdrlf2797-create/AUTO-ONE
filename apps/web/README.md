# 웹 앱 (예정)

웹 브라우저에서 AUTO-ONE을 설정하고 작업을 모니터링하는 화면입니다. Phase 1에서 TypeScript 기반의 반응형 UI를 추가할 예정입니다.

예정 기능:
- 로그인 및 사용자·기기 관리
- 자동화 작업 생성, 실행 상태, 이력 확인
- AI가 제안한 작업 계획과 위험도 표시
- 실행 승인, 취소, 일시 중지
- 연결된 PC 에이전트 상태 확인

웹 브라우저에는 PC의 임의 파일이나 프로그램을 직접 제어할 권한을 부여하지 않습니다. 로컬 작업은 명시적으로 연결·승인된 PC 에이전트를 통해서만 요청합니다.
