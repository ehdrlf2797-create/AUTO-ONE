# 로컬 PC 에이전트 (예정)

로컬 에이전트는 사용자가 승인한 PC 작업만 처리하는 별도 실행 구성요소입니다. 아직 실행 코드는 포함되어 있지 않습니다.

설계 원칙:
- 기본적으로 외부에서 임의로 들어오는 연결을 열지 않습니다.
- 인증된 제어 채널을 통해 명시적으로 요청된 작업만 받습니다.
- 파일·폴더·프로그램별 허용 범위를 확인합니다.
- 위험하거나 되돌리기 어려운 작업은 매번 사용자 승인을 요구합니다.
- 시간 제한, 취소, 중복 실행 방지, 실행 로그를 지원합니다.
- AI가 생성한 임의 셸 명령이나 코드를 검증 없이 실행하지 않습니다.
